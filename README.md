# SalvaGaia

Un tycoon por turnos en un planeta pixel-art: cada año construyes soluciones de Project Drawdown sobre las cuencas del mundo. Ganas cuando reviertes el cambio climático; pierdes si se acaba la Vida o la Comunidad.

| Archivo | Qué es |
|---|---|
| `DISENO.md` | El documento de diseño v1, con las decisiones de Sebas del 7 nov 2026 |
| `CLAUDE.md` | Las reglas para Claude Code en esta carpeta |
| `PROMPTS.md` | Los primeros 7 prompts, en orden |
| `data/soluciones.json` · `.csv` | Las 166 soluciones de Drawdown con su capa de juego v0 |
| `data/README_datos.md` | Las fuentes y los supuestos |
| `tools/gen_soluciones.py` | El script que regenera `soluciones.json` |

Nota del cuaderno: `Cuaderno Solarpunk Obsidian/5 Rumbo/Planetica - diseño del juego de la transición planetaria (v0).md`.
